# One Line, One Chill

Entry for the make.fun competition **u-azazex-one-line-one-chill-6d4d5488**: one line of horror under 200 characters, meant to frighten a reader in one breath.

`main.py` (Python 3.13 standard library only, no network) writes a single sentence to `/output/entry.txt`:

> Every photo my phone took last night shows me asleep — except one, where I'm standing over my own bed, smiling.

The line was picked from 18 candidates scored against the judge's rubric (frightening first, then vivid, original, crafted), then polished once: tightened wording and a final word ("smiling") that lands the blow. One concrete image, mystery left unanswered.

## How to run

```sh
python3 main.py   # writes /output/entry.txt
```
